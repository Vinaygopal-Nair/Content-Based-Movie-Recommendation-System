# 🎬 Content-Based Movie Recommendation System

A content-based movie recommender built with Python, pandas and scikit-learn. Give it a movie title and it returns the most similar movies, scored on plot overview, keywords, genres, director and cast. Everything is generated by the model from the TMDB 5000 dataset, nothing is hardcoded.

## 🚀 Features
- Merges the TMDB movies and credits files on movie ID and cleans 4,800+ movies
- Safe handling of missing and null data
- Case-insensitive, whitespace-tolerant title search (`inception`, `INCEPTION`, `  Inception` all work)
- Duplicate titles are detected and you pick the right one by year and director
- "Movie not found in database." for unknown titles, with a "Did you mean" hint
- Never recommends the movie you searched for
- Separate TF-IDF features per field, combined with a weighted cosine similarity
- Small quality boost (Bayesian weighted rating) so well-rated movies edge out ties
- Built-in sanity checks (`--check`) and a fixed seed-movie panel (`--panel`) for eyeballing quality

## 🧠 How it works
1. **Load and clean:** merge the two CSVs on ID, parse the JSON-like columns, keep the top 5 cast and the director.
2. **Features:** each field is vectorized separately with TF-IDF. Names are joined into single tokens (`christophernolan`, `sciencefiction`) so "Sam Worthington" and "Sam Mendes" don't look related.
3. **Similarity:** cosine similarity per field, then a weighted average. The weights live in `WEIGHTS` at the top of `project2.py` and are easy to tune.
4. **Ranking:** similarity, plus a small (max +15%) nudge from a movie's rating. Similarity always dominates.

## 🛠 Requirements
- Python 3.9+
- pandas, numpy, scikit-learn (see `requirements.txt`)

## 📁 How to run
1. Clone the repo:
   ```bash
   git clone https://github.com/<your-username>/Content-Based-Movie-Recommendation-System.git
   cd Content-Based-Movie-Recommendation-System
   ```
2. Install the libraries:
   ```bash
   pip install -r requirements.txt
   ```
3. Download the **TMDB 5000 Movie Dataset** from Kaggle and put `tmdb_5000_movies.csv` and `tmdb_5000_credits.csv` in a `data/` folder next to `project2.py`.
   To keep the files somewhere else, set `TMDB_DATA_DIR` to that folder instead.
4. Run it:
   ```bash
   python project2.py Inception
   python project2.py "12 Angry Men"
   python project2.py              # prompts: Enter movie name:
   python project2.py --top 10 "The Dark Knight"
   ```

Example output (yours will depend on the weights and data):

```text
Recommended movies similar to 'Inception':

1. ...
2. ...
```

## ✅ Testing and checking quality
```bash
python project2.py --check   # automated sanity checks (index alignment, search, no self-recommendation)
python project2.py --panel   # recommendations for a fixed list of seed movies
```
TMDB has no ground truth for "good recommendations", so quality is judged by reading the panel output, comparing against the old CountVectorizer version, and changing one weight at a time to see what moves.
